# Инструмент «Витрина продаж» — база наличия на складе

Инструмент для импорта Excel-таблиц в разных форматах, отображения наличия на сайте (витрина продаж) и управления остатками: редактирование, удаление, смена статуса.

---

## 1. Цели

| Задача | Описание |
|--------|----------|
| **Импорт Excel** | Загрузка файлов .xlsx / .xls / .csv в разных форматах (технику выкупают — таблицы приходят по-разному). |
| **Гибкий разбор** | Инструмент «понимает» разные форматы: маппинг колонок (описание, инв. номер, S/N, статус/условие). |
| **Витрина продаж** | Публичная или внутренняя страница «что в наличии» — карточки/таблица с фильтрами и поиском. |
| **Управление остатками** | Редактировать позиции, удалять, менять статус (в наличии / продано / зарезервировано и т.д.). |

---

## 2. Примеры форматов Excel (референс по вашим таблицам)

### Формат A — «Laptop» (лист с цветом строк)

| Колонка | Пример заголовка | Назначение |
|---------|-------------------|------------|
| Item Description | `Item Description` | Категория (например, «Laptops») |
| Описание товара | `User Item Description` | Полное описание: бренд, модель, CPU, экран, ОС, RAM, диск, графика |
| Инв. номер | `Inventory Number` | Уникальный ID, например `AC000000100596` |
| Серийный номер | `Serial number` | Например `PF1WQLHA` |
| Статус | *(нет колонки)* | **Цвет строки:** зелёный = в наличии, красный = нет в наличии / продан |

Пример строки:  
*Ноутбук: Lenovo 20RDS04A08 ThinkPad E15, Intel Core i7-10510U, 15.6", Win10 Pro 64, 16.0GB, 1x1TB SATA, 1x256GB SSD PCIe NVMe, Intel UHD Graphics, W*

### Формат B — «In Box / S/N / Tested / Name / Condition»

| Колонка | Пример заголовка | Назначение |
|---------|-------------------|------------|
| Номер в ящике | `In Box` | Порядковый номер (2, 3, … 20) |
| Серийный номер | `S/N` | Например `252GSL3`, `C02GP486Q6LT` |
| Внутренний ID | `Tested` | Числовой ID, например `022000152`, `10000723` |
| Название/описание | `Name` | Текст на EN/UA: модель, бренд, характеристики (MacBook Pro 13" M1 16GB, Dell Latitude, «Моноблок Dell Inspirion 7459» и т.д.) |
| Состояние | `Condition` | `Good`, `ABM locked`, `Battery broken`, `No Display`, `Keyboard does not work`, `DEP locked`, «Требует ремонта…» и т.д. |

Статус «в наличии» здесь выводится из колонки **Condition** (или отдельно вводится при импорте: какие значения считать «доступно»).

## 3. Единая модель данных (после импорта)

Внутри системы каждая позиция хранится в нормализованном виде:

```ts
interface InventoryItem {
  id: string;              // UUID или внутренний ID (генерируем при импорте)
  description: string;      // Описание товара (из "User Item Description" или "Name")
  category?: string;       // Опционально: Laptops, Monitors, и т.д. (из "Item Description" или авто)
  inventoryNumber?: string; // Inventory Number / Tested
  serialNumber?: string;   // Serial number / S/N
  condition?: string;      // Condition или производная от цвета/статуса
  status: 'available' | 'sold' | 'reserved' | 'unavailable'; // Для витрины и фильтров
  createdAt: string;       // ISO date
  updatedAt: string;
  sourceRow?: number;      // Для отладки: номер строки в исходном листе
}
```

- **Витрина продаж** по умолчанию показывает только `status === 'available'` (при необходимости — фильтр по статусу).
- Редактирование: менять описание, condition, **status** (остатки), инв. номер, S/N.
- Удаление: удалить позицию из базы (или перевести в статус «скрыто» — по желанию).

## 4. Маппинг колонок (как «понять» разные форматы)

### 4.1. Автоопределение по заголовкам

При загрузке Excel читаем первую строку и предлагаем сопоставление:

| Поле модели | Варианты заголовков для авто-маппинга |
|-------------|----------------------------------------|
| description | `User Item Description`, `Name`, `Description`, `Описание`, `Product` |
| category | `Item Description`, `Category`, `Type`, `Категория` |
| inventoryNumber | `Inventory Number`, `Tested`, `Internal ID`, `ID`, `Инв. номер` |
| serialNumber | `Serial number`, `S/N`, `Serial`, `Серийный номер` |
| condition | `Condition`, `Status`, `Состояние`, `Статус` |
| status | Отдельная колонка `Status` / `В наличии` или вывод из цвета строки / из Condition |

Если колонка не найдена — в маппинге оставить «Не использовать».

### 4.2. Ручной маппинг

Экран после загрузки файла:

1. Показать превью: первые 10–20 строк, заголовки колонок.
2. Для каждого поля модели — выпадающий список «Колонка Excel → Поле».
3. Правила для **status** (если нет колонки):
   - **Формат A:** при наличии информации о цвете ячейки/строки: зелёный → `available`, красный → `unavailable` (или `sold`). Если библиотека не отдаёт цвет — колонку «Статус» задать вручную или по умолчанию «в наличии».
   - **Формат B:** из Condition: например `Good` → `available`, остальное → `unavailable` или отдельное правило (настраиваемый список «значения = available»).
4. Кнопки: «Импортировать», «Отмена».

### 4.3. Чтение цвета строки (xlsx)

В .xlsx цвет фона строки можно читать (например, библиотека **xlsx** с опцией `cellStyles: true` или **SheetJS Pro**). Если используем бесплатную версию без стилей — статус задаём вручную при маппинге или добавляем колонку «Статус» в Excel перед импортом.

## 5. Функциональные блоки

### 5.1. Загрузка и разбор файла

- Принимать файлы: **.xlsx**, **.xls**, **.csv** (разделитель — авто или выбор).
- Библиотека: **SheetJS (xlsx)** в браузере или на сервере (Hono). Для больших файлов предпочтительно серверный парсинг.
- Результат: массив строк (объекты по заголовкам) + при возможности массив стилей (цвет строк) для первого листа.
- Выбор листа: если в книге несколько листов — выбор, с какого импортировать.

### 5.2. Экран маппинга

- Превью таблицы (заголовки + несколько строк).
- Выбор листа (если > 1).
- Для каждого поля: **Поле системы** → **Колонка в файле** (dropdown).
- Настройка статуса: «По какой колонке/правилу определять статус» (колонка Status / цвет / Condition с правилами).
- Кнопка «Импорт» → валидация → сохранение в хранилище (см. ниже).

### 5.3. Хранилище данных

- **Вариант 1:** API (Hono) + JSON-файл на сервере или Cloudflare KV/D1 — полный CRUD.
- **Вариант 2:** Только фронт: localStorage / IndexedDB, экспорт JSON/Excel — без бэкенда для старта.
- Рекомендация: API + один общий файл `inventory.json` или таблица в D1, чтобы витрина и админка работали с одними данными.

### 5.4. Витрина продаж (публичная или в зоне Tools)

- Страница: например `/marketplace/stock` или `/tools/inventory` (если только для своих).
- Отображение: карточки или таблица — описание, категория, состояние, инв. номер (опционально), кнопка «Запросить КП» / «Уточнить».
- Фильтры: категория, состояние, поиск по тексту.
- Показывать только `status === 'available'` (или выбор «Показать проданные» для внутренней витрины).

### 5.5. Управление остатками (админка)

- Список всех позиций: таблица с колонками (описание, инв. номер, S/N, condition, **status**, даты).
- Действия по строке:
  - **Редактировать** — изменить описание, condition, **status** (в наличии / продано / зарезервировано / недоступно), инв. номер, S/N.
  - **Удалить** — убрать из базы (с подтверждением).
- Массовые действия (опционально): смена статуса выбранных строк, экспорт в Excel.
- Импорт снова: «Добавить из файла» → тот же поток (маппинг → импорт). Режим: **добавить только новые** (по S/N или инв. номеру) или **заменить всё** / **обновить по ключу**.

## 6. Размещение в структуре сайта

| Вариант | Путь | Кто видит |
|---------|------|-----------|
| Витрина как часть маркетплейса | `/marketplace/stock` или `/marketplace/catalog` (источник данных = импорт) | Все / только B2B |
| Управление импортом и остатками | `/tools/inventory` | Только авторизованные (PIN, как в NEXX) |

Итого:

- **Витрина продаж:** `/marketplace/stock` — что в наличии (данные из инструмента).
- **Инструмент импорта и остатков:** `/tools/inventory` — загрузка Excel, маппинг, список позиций, редактирование, удаление, смена статуса.

## 8. Пошаговый сценарий (пользователь)

1. Зайти в **Инструменты** → **Витрина / Наличие** (`/tools/inventory`).
2. Нажать **«Загрузить Excel»** → выбрать файл (.xlsx / .xls / .csv).
3. Выбрать лист (если несколько), посмотреть превью.
4. Настроить маппинг: какая колонка → описание, инв. номер, S/N, состояние, статус (или из цвета).
5. Нажать **«Импортировать»** → данные появляются в общем списке.
6. В списке: **редактировать** (в т.ч. статус «в наличии»/«продано»), **удалить** ненужное.
7. На сайте витрина **«В наличии»** (`/marketplace/stock`) подтягивает те же данные и показывает только доступные позиции; при необходимости клиент жмёт «Запросить КП».
