# Мой кабинет — кнопки и функционал

Краткий список разделов, кнопок и возможностей кабинета партнёра/продавца.

---

## 1. Дашборд (`/my`)

**Назначение:** сводка по витрине и запросам КП.

| Элемент | Описание |
|--------|----------|
| Карточка «Позиций на витрине» | Количество доступных позиций и всего позиций |
| Карточка «Новых запросов КП» | Количество новых запросов за текущий период |
| Карточка «Последнее обновление прайса» | Дата/время последнего импорта |
| Блок «Последняя активность» | Текст о последнем обновлении и количестве позиций |
| **Быстрые действия** | |
| Ссылка «Обновление прайса и остатков» | Переход в раздел импорта и таблицы позиций |
| Ссылка «Настройки» | Переход в настройки профиля и уведомлений |

---

## 2. Управление пользователями (`/my/users`)

**Назначение:** создание и управление пользователями кабинета покупателя (доступ к витрине и запросам КП).

| Элемент | Описание |
|--------|----------|
| Список пользователей | Таблица/карточки пользователей с ролями и статусом |
| Кнопка «Добавить пользователя» | Создание нового пользователя (логин, пароль, роль) |
| Редактирование пользователя | Изменение данных, блокировка/разблокировка |
| Удаление пользователя | Удаление доступа (при наличии в интерфейсе) |

---

## 3. Обновление прайса и остатков (`/my/inventory`)

**Назначение:** импорт прайса, управление позициями и партиями, подготовка витрины.

| Элемент | Описание |
|--------|----------|
| **Очистка витрины** | |
| Кнопка **«Очистить всё и загрузить новые стоки»** | Удаляет все позиции и все партии. После подтверждения витрина пустая — можно загрузить новый файл с нуля. |
| Подтверждение | Диалог: «Удалить все позиции (N) и партии (M)?» — [Да, очистить всё] / [Отмена] |
| **Импорт через API** | |
| Выбор файла | input file (.xlsx, .xls, .csv) |
| Кнопка «Загрузить на сервер» | Отправка файла на API (если подключён) |
| **Импорт из Google Таблиц** | |
| Поле «Ссылка» | Вставка URL таблицы (вид или export) |
| Кнопка «Загрузить» | Загрузка данных по ссылке (обход CORS через API), далее маппинг и импорт как у файла |
| **Импорт из файла (локальный)** | |
| Выбор файла | Загрузка Excel/CSV с диска |
| Выбор листа | Если в файле несколько листов |
| Маппинг колонок | Сопоставление колонок файла с полями (описание, цена, инв. номер, статус и т.д.) |
| Выбор/создание партии | Импорт в существующую партию или создание новой (страна, дата, поставщик и т.д.) |
| Кнопка «Импортировать» | Добавление выбранных строк в инвентарь |
| **Партии** | |
| Таблица партий | Страна, дата, откуда закупка, от кого, действия |
| Удаление партии | Удаление партии (позиции остаются, но без привязки к партии) |
| **Таблица позиций** | |
| Фильтры | По партии, стране, поставщику и др. |
| Редактирование позиции | Редактирование полей (описание, цена, категория, статус, ОЗУ, процессор и т.д.) |
| Удаление позиции | Удаление одной позиции |
| Отображение колонок | Инв. номер, описание, цена, валюта, категория, статус, партия и т.д. |

---

## 4. Подбор ноутбуков (`/my/laptops`)

**Назначение:** подбор ноутбуков по параметрам из базы/каталога.

| Элемент | Описание |
|--------|----------|
| Фильтры/форма подбора | Параметры (бренд, процессор, ОЗУ, диагональ и т.д.) |
| Кнопка «Подобрать» / поиск | Запуск подбора по заданным критериям |
| Результаты подбора | Список/таблица подходящих ноутбуков |

---

## 5. Настройки (`/my/settings`)

**Назначение:** профиль партнёра и уведомления.

| Элемент | Описание |
|--------|----------|
| Профиль | Редактирование названия, контактов, реквизитов (в зависимости от реализации) |
| Уведомления | Включение/отключение уведомлений о новых запросах КП (email, push и т.д.) |
| Кнопки сохранения | Сохранение изменений настроек |

---

## Сводка по кнопкам «действие»

| Раздел | Кнопка/действие |
|--------|------------------|
| Дашборд | Переход: Обновление прайса, Настройки |
| Управление пользователями | Добавить пользователя, Редактировать, Удалить (если есть) |
| Обновление прайса и остатков | **Очистить всё и загрузить новые стоки**, Загрузить на сервер (API), Импортировать (файл), Удалить партию, Редактировать/удалить позицию |
| Подбор ноутбуков | Подобрать / Поиск |
| Настройки | Сохранить (профиль, уведомления) |

Файл можно дополнять по мере появления новых кнопок и разделов.
