# Карта разработки: Restart B2B Platform

> Лендинг + торговая площадка для B2B + личные инструменты (база знаний).  
> Референс: [restartsp.com](https://restartsp.com/), база знаний — [NEXX-LAST](https://github.com/PlevanDM/NEXX-LAST).

---

## 1. Цели проекта

| Компонент | Описание |
|-----------|----------|
| **Лендинг** | Корпоративный лендинг 2026: услуги, офисы, партнёры, CTA (Quote / Callback). |
| **Торговая площадка B2B** | Каталог оборудования, галерея в корпоративном стиле, запрос КП, фильтры. **Витрина продаж** — наличие на складе (данные из инструмента импорта Excel). |
| **Личные инструменты** | Закрытая зона: база знаний, справочники, **инструмент «Витрина продаж»** (импорт Excel, маппинг колонок, управление остатками), по аналогии с NEXX. |

## 4. Дизайн: корпоративный стиль 2026

- **Стиль:** Чистый, профессиональный, доверительный. Минимум декора, акцент на контенте и типографике.
- **Сетка:** Чёткая модульная сетка, много «воздуха», крупные блоки.
- **Галерея B2B:** Крупные превью, категории, фильтры, состояние «нет результатов». Единый формат карточек (фото + название + краткое описание + CTA).
- **Цвета и шрифты:** Определить на основе текущего сайта и лого Restart; при необходимости — тёмные акценты и нейтральный фон.
- **Компоненты:** Кнопки (primary/secondary), карточки, баннеры, формы, футер с колонками (Information, Navigation, Offices).
